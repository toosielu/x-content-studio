# Delegated editorial work

Read when assigning research, strategy, writing, or independent review. These roles are supplied by the runtime, not bundled with this skill. If a role is unavailable, use an available agent with a bounded brief or do the work directly; no installation is needed.

## Select stages by unresolved needs

| Need | Role and useful output |
| --- | --- |
| Claims require verification | `x_scout`: claim, direct source URL, what it supports, relevant publication/event/checking dates, unresolved gap. |
| Supplied references merit structural analysis | `viral_analyst`: adaptable hook, pacing, and sharing mechanism; distinctive expression to avoid copying. |
| Central angle remains unresolved | `content_strategist`: reader benefit, supporting evidence, selected angle and outline. For angle exploration, usually up to three materially different options; honor the requested number. |
| Prose needs drafting or substantial revision | `tweet_writer`: requested draft, source mapping for verifiable claims, uncertainty preserved. |
| Source-heavy, logically difficult, or substantial prose benefits from independent review | `editor_reviewer`: revised content, material corrections, remaining uncertainty. |

For a research-backed new piece, the sequence can be research → strategy → writing → review when all four needs exist. Pure style edits need no research. A fact-check stops at supported corrections unless a rewrite is requested. A finished-content request needs the chosen angle rather than unrequested alternative hooks.

Run dependent stages sequentially. Independent bounded research questions can run in parallel, then merge evidence before drafting. The parent owns the final evidence and editorial check even when delegation is skipped.

## Carry the shared brief

Pass only relevant fields: requested format and length; intended reader and purpose; settled title or angle; confirmed voice preferences; wording/examples to preserve; source experience that must not become user experience; and unresolved evidence gaps.

Include the applicable human-voice and content-decisions criteria in writing/review briefs, not every reference file or full transcripts. Keep claim-to-source mappings compact. Later stages may flag a problem but should not silently reopen settled choices. Review should repair actual weaknesses rather than rewrite merely to demonstrate participation.
